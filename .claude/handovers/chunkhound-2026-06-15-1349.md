## What was done
**Root cause:** the global MCP server in `~/.claude/settings.json` launches in every session; `find_project_root()` treated any `.git` repo as a ChunkHound project, and with no `database.path` set it defaulted the DB to in-tree `<repo>/.chunkhound/db`. Config alone can't fix it (single global `database.path` collides; no path templating).

**Two env-gated fork patches (default to upstream behavior when env unset):**
- `chunkhound/core/config/config.py` (~L383, `# fork:`) — `CHUNKHOUND_DB_ROOT` → DB defaults to `<root>/<project-name>` instead of in-tree.
- `chunkhound/utils/project_detection.py` (`# fork:`) — `CHUNKHOUND_REQUIRE_PROJECT_CONFIG` → only `.chunkhound.json` opts a repo in (no `.git` auto-claim).
- `tests/test_db_path_isolation.py` — 5 regression tests (the merge safety net).

**Env (in `~/.oh-my-zsh/custom/zsh_alias.sh`):** `CHUNKHOUND_DB_ROOT=$HOME/workbench/chunkhound-dbs`, `CHUNKHOUND_REQUIRE_PROJECT_CONFIG=1`.

**Config fixes:** repointed 2 `.chunkhound.json` (tracontime, fiber-locator) + 7 `--db` entries in 5 melangeX `.mcp.json` to `chunkhound-dbs/<name>`. Added `.chunkhound/` to `.gitignore` in repos that lacked it.

**Cleanup:** deleted ~40 stale in-tree `.chunkhound` DB dirs (~14 GB+).
